# Архітектура AI-агента

## Призначення
Автоматизація ініціалізації проєкту, конфігурації збірки, тестування та створення CI-пайплайну на базі Python.

## Використані Skills
1. `project-scaffold`: генерація файлової структури, вихідного коду та .gitignore.
2. `build-and-test`: налаштування віртуального оточення venv, requirements.txt, скриптів збірки та тестів на базі pytest.
3. `github-actions`: створення кросплатформного workflow для GitHub Actions.

## Доступні Commands (Prompts)
- `git-init`: налаштування контролю версій та перевірка .gitignore.
- `create-project`: виклик скіла project-scaffold.
- `create-build`: виклик скіла build-and-test.
- `create-actions`: виклик скіла github-actions.
- `check`: неруйнівна перевірка коректності коду та тестів.
- `init`: оркестратор, що викликає всі команди послідовно.

## Обробка помилок оркестратором
Оркестратор перевіряє код повернення після кожного кроку і негайно перериває виконання (fail-fast), якщо бодай один етап зазнав невдачі.
